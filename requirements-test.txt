# Test-only dependencies.
#
# `python3 -m unittest discover -s tests` needs these to run the full suite
# outside the container image. Inside the container they are already installed
# by requirements.txt, so this file exists for one person: whoever cloned the
# repo and ran the tests on the host.
#
# Without them, the six cookie-integrity tests SKIP with a reason instead of
# erroring. They are not counted in a total taken outside the container, and a
# "21 passed" from a bare checkout is not the same claim as the container's 27.
#
#     python3 -m pip install -r requirements-test.txt
#
# All three are needed, and each one was measured, not guessed:
#
#  - fastapi and python-multipart: installing fastapi alone left the app
#    erroring at import. app.main declares `Form(...)` parameters at module
#    scope and FastAPI raises ("Form data requires python-multipart") the moment
#    it sees them.
#  - httpx: FastAPI's TestClient is built on httpx. Without it the client cannot
#    be constructed, and — this is the part that cost a reviewer an hour — the
#    tests that need it SKIP, so the suite reports "OK (skipped=9)" and the word
#    that survives in a summary is OK. Nine tests that did not run read as nine
#    tests that passed.
#
# So the list was short one package while the skip message told the reader to
# install from this list. The instruction and the remedy disagreed, and a reader
# who followed the remedy did not fix the problem. That is worse than an error,
# because an error is a result. Three packages now, and the guard refuses to
# skip quietly (see _have_test_deps in the test file).

# pinned to the version the container image runs; measure with:
# docker compose exec -T bitwitch pip show fastapi
# left unpinned until measured because an unmeasured pin is the bug this file
# exists to fix.
fastapi

# same rule, same reason: measure with
# docker compose exec -T bitwitch pip show python-multipart
python-multipart

# FastAPI's TestClient imports httpx. Naming it here is not decoration: without
# it the nine code-level tests skip, and a skip count buried in a summary is how
# a suite that did not run gets reported as a suite that passed.
httpx
